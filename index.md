# Clappie

Claude Code is incredible. But it's just a chat box.

What if it could run background tasks while you sleep? Text you when something's urgent? Remember everything about you? Show beautiful terminal UIs? Manage your notifications intelligently? Spawn parallel agents to handle work?

That's Clappie.

**One skill file. Tiny. Hackable. Yours.**

No bloated frameworks. No complex setup. Just Claude Code plus a few hundred lines of code that turn it into a personal operating system.

---

## What You Get

### Terminal UIs That Don't Suck
Beautiful pixel art interfaces rendered directly in your terminal. Buttons, toggles, inputs, lists - a full component library. Dark mode. Light mode. An animated garden with a crab.

### AI Cron Jobs
Background monitors that run autonomously. Define tasks in plain English. No YAML. No config hell. Claude spawns subagents to do the work while you focus on other things.

### Smart Notifications
Raw dirty goes in, curated clean comes out. 20 emails become 4 actionable items. Plain English rules. Bidirectional sync - read something on your phone, it disappears here.

### Parallel Agents
Fire-and-forget async tasks. Spawn Claude sessions that run in the background. Send a task from your phone, get a response when it's ready. Multiple sidekicks running simultaneously.

### Text Your AI
Telegram integration. Send tasks from anywhere. Reply threading works naturally. Attachments, photos, documents. Your AI in your pocket.

### It Actually Remembers
Persistent memory across all sessions. Who you are, what you like, who you know. Plain text files you can read and edit. No creepy database.

### Safety First
Human approval queue for risky actions. Send email? Chore. Delete file? Chore. AI suggests, you decide. Full audit trail.

## Quick Start

```bash
# Install the skill
claude install clappie

# Start background services
clappie background start

# Open the dashboard
clappie display push notifications
```

## Why Clappie?

Other AI assistants are either too simple (just chat) or too complex (enterprise frameworks with 50 config files).

Clappie is different:

- **Tiny** - One skill file. Read the whole thing in 10 minutes.
- **Hackable** - Plain JavaScript. No build step. Edit and reload.
- **File-based** - Everything is `.txt` files. No database. Version control friendly.
- **Terminal-native** - Not a web app pretending to be a CLI. Real terminal UIs.
- **Open architecture** - Sockets, files, text. Easy to integrate with anything.

It's the personal assistant you'd build yourself if you had a weekend. Except someone already built it.
